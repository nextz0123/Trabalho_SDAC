Introdução

O que é programar, o que é a POO e porque é importante.

O que é programação?

Programar é escrever instruções que o computador consegue executar para resolver um problema, desde uma calculadora simples até um videojogo.

O que é a Programação Orientada a Objetos?

A Programação Orientada a Objetos (POO) é uma forma de organizar o código em objetos. Cada objeto junta dados (o que ele sabe) e comportamentos (o que ele faz). Um objeto Carro, por exemplo, tem marca e velocidade e sabe acelerar.

Para que serve e porque é importante?

  • Organiza programas grandes em partes pequenas e fáceis de perceber
  • Permite reutilizar código em vez de o repetir
  • Facilita a manutenção e o trabalho em equipa

Ideia-chave: em vez de um programa com instruções soltas, temos objetos que colaboram entre si, tal como no mundo real.

O que é o C#?

A linguagem e a plataforma .NET onde os programas correm.

O C# (lê-se «C sharp») é uma linguagem moderna criada pela Microsoft no início dos anos 2000. É orientada a objetos, fortemente tipada e tem uma sintaxe clara e segura.

O C# funciona sobre a plataforma .NET, que compila e executa os programas e oferece bibliotecas prontas a usar. Hoje corre em Windows, Linux e macOS.

Encapsulamento

Proteger os dados do objeto.

O que é? Esconder o estado interno do objeto e só permitir alterá-lo através de métodos ou propriedades. Para que serve? Evita valores inválidos e protege os dados.

public class Conta
{
    private decimal _saldo;
    public decimal Saldo => _saldo;

    public void Depositar(decimal valor)
    {
        if (valor <= 0)
            throw new ArgumentException("Valor inválido");
        _saldo += valor;
    }
}

O campo _saldo é private, logo ninguém o altera de fora. A propriedade Saldo só permite ler, e o método Depositar valida o valor antes de alterar.

Experimenta: valor positivo, negativo ou zero.

Herança

Reutilizar o código de outras classes.

O que é? Uma classe derivada herda propriedades e métodos de uma classe base. Usa-se : na declaração e a relação é do tipo «é um»: um Carro é um Veículo. Assim, o código comum escreve-se só uma vez.

        Console.WriteLine("Motor ligado");

public class Carro : Veiculo

    public int Portas { get; set; }

var c = new Carro { Marca = "Toyota", Portas = 5 };
c.Ligar(); // método herdado

Polimorfismo

A mesma chamada, comportamentos diferentes.

O que é? Objetos diferentes respondem à mesma chamada de formas diferentes. Em C# usa-se virtual na classe base, que permite redefinir o método, e override na classe derivada, que fornece a nova versão. O método executado depende do tipo real do objeto.

public class Animal
{
    public virtual string EmitirSom() => "...";
}

public class Cao : Animal
{
    public override string EmitirSom() => "Au au!";
}

public class Gato : Animal
{
    public override string EmitirSom() => "Miau!";
}

Animal a = new Gato();
Console.WriteLine(a.EmitirSom()); // Miau!
Escolhe um animal.

Abstração

Mostrar só o essencial e esconder os detalhes.

O que é? Mostrar apenas o que é essencial e esconder os detalhes. Porque é importante? Simplifica o uso das classes e define regras comuns. Uma abstract class não pode ser instanciada, e um método abstract não tem corpo: as classes derivadas são obrigadas a implementá-lo.

public abstract class Forma
{
    public abstract double Area();

    public void Mostrar() =>
        Console.WriteLine($"Área: {Area():F2}");
}

public class Circulo : Forma
{
    public double Raio { get; set; }
    public Circulo(double raio) => Raio = raio;

    public override double Area() =>
        Math.PI * Raio * Raio;
}

// var f = new Forma(); // ERRO: classe abstrata
new Circulo(2).Mostrar(); // Área: 12.57

Classes e objetos

O molde e as instâncias criadas a partir dele.

Uma classe é o molde que descreve como são os objetos. Um objeto é uma instância concreta criada a partir desse molde com new.

ClasseObjeto
ÉO moldeUma instância do molde
ExemploCarroc1 (Toyota Yaris), c2 (Honda Civic)
QuantidadeDefinida uma vezPodem existir muitos

Propriedades, métodos e construtores

  • Propriedades: guardam os dados (Marca, Modelo, Velocidade)
  • Métodos: são as ações (Acelerar)
  • Construtor: prepara o objeto quando é criado
public class Carro
{
    public string Marca { get; set; }
    public string Modelo { get; set; }
    public int Velocidade { get; private set; }

    public Carro(string marca, string modelo)
    {
        Marca = marca;
        Modelo = modelo;
    }

    public void Acelerar(int kmh) => Velocidade += kmh;
}

var c1 = new Carro("Toyota", "Yaris");
var c2 = new Carro("Honda", "Civic");
c1.Acelerar(20);
c1.Velocidade = 0 km/h

Exemplo prático

Um sistema de gestão de veículos que junta tudo.

Um pequeno sistema que junta tudo o que vimos: classes, objetos, propriedades, métodos, construtores, herança, encapsulamento e polimorfismo.

public class Veiculo
{
    public string Marca { get; }
    public string Modelo { get; }
    private int _velocidade;              // encapsulamento
    public int Velocidade => _velocidade;

    public Veiculo(string marca, string modelo)   // construtor
    {
        Marca = marca;
        Modelo = modelo;
    }

    public void Acelerar(int kmh)
    {
        if (kmh <= 0) return;
        _velocidade += kmh;
    }

    public virtual string Descrever() =>
        $"{Marca} {Modelo} a {Velocidade} km/h";
}

Dados protegidos com private, construtor para criar o objeto e um método virtual que as derivadas podem mudar.

public class Carro : Veiculo                  // herança
{
    public Carro(string marca, string modelo)
        : base(marca, modelo) { }

    public override string Descrever() =>     // polimorfismo
        $"Carro: {base.Descrever()}";
}

public class Mota : Veiculo
{
    public Mota(string marca, string modelo)
        : base(marca, modelo) { }

    public override string Descrever() =>
        $"Mota: {base.Descrever()}";
}

Carro e Mota herdam tudo de Veiculo e redefinem apenas Descrever().

var frota = new List<Veiculo>
{
    new Carro("Toyota", "Yaris"),
    new Mota("Yamaha", "MT-07")
};

foreach (var v in frota)
{
    v.Acelerar(60);
    Console.WriteLine(v.Descrever());
}

// Carro: Toyota Yaris a 60 km/h
// Mota: Yamaha MT-07 a 60 km/h

A lista guarda Veiculo, mas cada objeto usa a sua própria versão de Descrever().

Vantagens e desvantagens

O que a POO traz de bom e onde pode complicar.

♻️ Reutilização

A herança evita repetir código.

🗂️ Organização

Cada classe tem o seu papel.

🔧 Manutenção

Alterar uma classe afeta pouco o resto.

🧱 Modularidade

Partes independentes e testáveis.

📚 Complexidade inicial

Há muitos conceitos para aprender no início.

🌀 Excesso de abstração

Demasiadas classes podem complicar programas simples.
